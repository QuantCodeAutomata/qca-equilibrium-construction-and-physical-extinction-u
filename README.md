# Arrow-Debreu Equilibrium with Time-Varying Beliefs

A computational research project studying the Arrow-Debreu equilibrium in a two-investor
economy where one investor (the "dogmatist") holds time-varying, potentially distorted
beliefs about the endowment process. The project provides numerical implementations of
pricing formulas, Hansen-Scheinkman factorizations, long-run yield analysis, and
general-γ approximation bounds derived in the companion theoretical paper.

## Economic Model

### Setup

The economy is endowed with a single Lucas tree whose log-dividend follows a Brownian
motion under the *rational* probability measure **P**:

```
d log D_t = (μ − ½σ²) dt + σ dB_t,    D_0 given
```

Two investors share the economy:

| Agent | Label | Belief | Initial wealth share |
|-------|-------|--------|----------------------|
| Rationalist | R | P (correct) | 1 − s₀ |
| Dogmatist | N | Q (distorted) | s₀ |

The dogmatist's likelihood ratio (Radon-Nikodym derivative) satisfies:

```
log ξ_t = σ ∫₀ᵗ η_s dB_s  −  ½σ² ∫₀ᵗ η_s² ds
```

where η_t is a *deterministic* belief-distortion path (the "eta path").  Key path
integrals are:

```
A_t = ∫₀ᵗ η_s² ds     (quadratic variation of log ξ)
H_t = ∫₀ᵗ η_s  ds     (cumulative belief drift)
```

Both investors have CRRA utility with the same coefficient γ and discount rate ρ.

### Equilibrium Objects

**Wealth ratio** (dogmatist-to-rationalist):

```
log w_t = log w_0 + (1/γ) log ξ_t,    w_0 = s_0 / (1 − s_0)
```

**Consumption shares**:

```
c_R,t = D_t / (1 + w_t),    c_N,t = w_t D_t / (1 + w_t)
```

**State-price density** (SDF):

```
log π_t = −ρt − γ log(D_t/D_0) + γ log((1 + w_t)/(1 + w_0))
```

**Rationalist benchmark yield** (equilibrium short rate in the pure-rationalist economy):

```
r_R = ρ + γμ − ½γ(γ+1)σ²
```

## Experiments

### Exp 1 — SDF and Wealth-Share Paths (`exp/exp1_sdf_paths.py`)

Simulates the stochastic discount factor and the dogmatist's wealth share under three
η-path specifications (fading pessimism, fading alternating, constant cyclical).
Produces time-series plots of `log π_t`, `s_t = w_t/(1+w_t)`, and the benchmark
martingales `M_t^R` and `M_t^N`.

### Exp 2 — Hansen-Scheinkman Factorizations (`exp/exp2_factorization.py`)

Verifies the factorization identity

```
π_t = exp(−r_R · t) · M_t^{a,b} · Φ_{a,b}(0, H_0, w_0) / Φ_{a,b}(t, H_t, w_t)
```

numerically for a grid of (a, b) pairs and η-path types.  Also checks the companion
identity `M_t^R · w_t^γ = w_0^γ · exp(−γσ²H_t) · M_t^N`.

### Exp 3 — Exact γ = 1 Bond Prices (`exp/exp3_section4_gamma1.py`)

Uses the closed-form Section 4 formulas to compute:
- Zero-coupon bond prices and yield spreads versus r_R
- Forward-rate spreads and forward-growth shifts
- Bond price premia as functions of maturity T

Sweeps over the fading-pessimism and constant-cyclical η-paths.

### Exp 4 — Long-Run Yield Analysis (`exp/exp4_long_run.py`)

Studies the limit behaviour of long bond yields and forward rates.  Classifies each
η-path according to whether A_T and H_T diverge, and computes the limiting long yield

```
r_∞ = r_R + γσ² min(H̄, 0)
```

when the limit H̄ = lim_{T→∞} H_T/T exists.  Plots the term structure of yields and
the convergence of the forward-density process Z_t^T.

### Exp 5 — General-γ Approximation (`exp/exp5_approximation.py`)

Tests the approximation

```
P̂(t,T) = exp(−r_R(T−t)) · (1+w_t)^{−γ} · (1 + q_{t,T})
```

against Monte Carlo bond prices for γ ∈ {0.5, 1, 2, 5}.  Plots the error bound

```
e_{t,T} ≤ K_γ · exp(−γ/(2(1+γ)²) · σ² · A_{t,T})
```

and the empirical L1 forward-density error.

## Usage

### Quick Start

```python
import numpy as np
from src.model import Parameters, simulate_brownian, log_sdf, dogmatist_share
from src.paths import eta_fading_pessimism, compute_path_objects

# 1. Define economy parameters
params = Parameters(mu=0.02, sigma=0.02, rho=0.01, gamma=1.0, D0=1.0, s0=0.3)

# 2. Simulate Brownian paths
T, dt, n_paths = 50.0, 0.01, 500
t_grid, dB, B_t = simulate_brownian(T, dt, n_paths, seed=0)

# 3. Build the η-path and its integrals
path = compute_path_objects(t_grid, lambda t: eta_fading_pessimism(t, eta0=1.0), dt)

# 4. Compute the SDF and dogmatist wealth share
from src.model import log_endowment, log_xi, log_w
log_D   = log_endowment(t_grid, dB, dt, params)
log_xi_ = log_xi(path['eta'], dB, dt, params.sigma, params.gamma)
log_w_  = log_w(log_xi_, params.w0, params.gamma)
log_pi  = log_sdf(t_grid, log_D, log_w_, params)
s_t     = dogmatist_share(log_w_)

print(f"Mean dogmatist share at T={T}: {s_t[-1].mean():.4f}")
```

### Running an Experiment

```bash
python exp/exp1_sdf_paths.py      # generates results/exp1_*.png
python exp/exp3_section4_gamma1.py
```

python -m pytest tests/ -v
